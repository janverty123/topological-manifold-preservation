# Assets

No static assets (images, diagrams, etc.) currently belong to this
project outside of generated experiment plots, which live under
`outputs/experiments/EXP-XXX/plots/` instead (co-located with the
experiment that produced them, per DESIGN_PRINCIPLES.md).

This folder exists to match the target repository structure. If
paper-ready figures or standalone diagrams are added later that aren't
tied to one specific experiment, they belong here.
