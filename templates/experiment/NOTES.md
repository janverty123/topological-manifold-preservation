# Experiment Template — Notes

This template's folder layout matches what the code ACTUALLY creates
(verified against src/train.py, src/train_general.py, scripts/_common.py,
run_multitask.py), not a generic placeholder structure. Specifically:

- `logs/` — one `.jsonl` file per method (`finetune.jsonl`, `ewc.jsonl`,
  `tmp.jsonl`), one JSON record per epoch, auto-created by
  `JsonlLogger` (src/train.py / src/train_general.py). There is no
  single `training.log` text file -- these structured JSONL logs ARE
  the training log, and are also what `compare_results.py` /
  `compare_multitask_results.py` read to generate plots and stats.
- `models/` — saved `.pt` checkpoints (`task1_base_model.pt` /
  `task0_base_model.pt`, plus `{method}_final_model.pt` per method).
  Called `checkpoints/` in some generic project templates; this
  codebase calls it `models/` everywhere (code, docs, prior
  conversation history) -- kept consistent with that rather than
  renamed, to avoid contradicting the implementation.
- `diagrams/` — EXP-001 (2-task) ONLY: saved persistence-diagram
  artifacts (`base_point_cloud.npy`, `diagram_base.npy`) from the TMP
  method's `run_tmp.py`. EXP-002 (multi-task) does not currently save
  these separately.
- `plots/` — `.png` outputs from `compare_results.py` /
  `compare_multitask_results.py`.

`metadata.yaml`, `README.md`, and `metrics.json` in this template are
NOT auto-generated by any script -- they're meant to be manually
copied into a new `outputs/experiments/EXP-XXX/` folder and filled in
by whoever (human or Claude) runs and writes up that experiment.
